# 💸 BillBuddy — Smart Expense Tracker

**Track. Budget. Save. Smarter.**

BillBuddy is a browser-based expense management app built with React, Vite, and JavaScript to help users track expenses, manage budgets, scan receipts, and understand spending patterns.

🌐 **Live Demo:** https://bill-buddy-topaz.vercel.app/

## ✨ Features
- Track, search, filter, and manage transactions.
- Set monthly budgets and monitor spending.
- Scan receipts using Tesseract.js OCR.
- Get smart spending alerts and savings recommendations.
- View monthly analytics and spending forecasts.
- Export transactions to CSV.
- Responsive design with browser-based data storage.

## 🛠️ Tech Stack
React · Vite · JavaScript · CSS · IndexedDB · localStorage · Tesseract.js

## 🚀 Run Locally

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd billBuddy
npm install
npm run dev
```

## 📦 Production Build

```bash
npm run build
npm run preview
```

**Note:** Transactions and budgets are stored locally in the browser and are not synchronized across devices.
